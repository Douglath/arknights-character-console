# v1.0.0 验证范围

环境：Windows、Python 3.13、Microsoft Edge Chromium（WebGL 2）。最低要求为 Python 3.10；macOS/Linux 启动脚本已提供，未在这些系统上实际运行。

资源检查：426 个 GLB 文件头、长度和 SHA256 与原索引匹配；426 个 asset/key 唯一，423 个精确 form 与上游形态对应表一致；426 张缩略图和所有字体保持原字节。全部 GLB 的 buffer/image 外部 URI 为零，不需要额外下载模型资源。六个字体族共223个 WOFF2 及完整 OFL 许可在包内。

隐私与范围：模型 JSON 字符串及公开文本未发现机器绝对路径、私人会话链接或账号凭证。源中的 PMREM 论文链接属于第三方代码注释，无联网运行行为。未携带 PV、场景或原始官方图包。

浏览器验证覆盖：

- 搜索 Lancet-2 返回1条，一星筛选12条，档案/名录/全景视图切换和结果数。
- 伊内丝、阿米娅、缪尔赛思、安赛尔、夜刀、Lancet-2、虎狼丸、泰拉大陆调查团、银灰、夕、浊心斯卡蒂共11个不同样本实际加载与绘制。
- 待机、跑动、测试动作及骨骼控件；确定性采样检测到跑动骨骼姿态变化及实际绘制调用。
- GLB 下载文件与索引 SHA256 一致。
- 单体 HTML 实际导出，使用 file URL 在浏览器断网模式打开，切换跑动与骨骼成功，完整许可已嵌入。
- 页面没有 JavaScript 错误、HTTP失败或外部网络依赖。

启动器检查：绑定本机、默认端口占用回退、资源缺失提示、目录访问/路径遍历拒绝和 GET/HEAD 一致性通过。

完整 Release 在干净解压路径重复逐文件清单和上述浏览器验证。下载后可用 `python tools/verify.py` 复查。检查结果适用于此发布字节，不等于426个模型均经过逐一完整视觉验收，也不保证每个模型具备相同动作范围。
