# 版本来源与打包边界

版本：v1.0.0，2026-10-03。

本次从授权的上游控制台快照独立提取，基准提交 `c612899a0493916d78ff32993647bd3a91066023`。发布为独立仓库和全新 Git 历史，不复制上游私有历史。控制台运行文件与此前 `2f022e270eff01876b4d069aa386fab231783339` 相同；后续两次提交仅涉及未附带的 PV 文档和封面。

提取范围：roster/site、roster/shared、roster/data、roster/assets、索引引用的 426 个 GLB，以及实际使用的 Three.js 模块。所有模型、缩略图和字体保留原始字节。`version.json` 与 `manifests/models.json` 保存版本、精确身份和模型摘要。

独立发布适配：替换本机启动器，移除旧广场服务入口，将展示分组标题从“PV篇章”改为“主题分组”，增加 CC BY-NC 4.0 模型许可入口并在单体 HTML 中内嵌完整许可；增加文档、清单及校验工具。模型本身未修改。

没有附带私人会话、机器路径、账号配置、原始官方立绘库、PV 成片/配乐或第一幕场景。源资料包的摘要仅作来源追溯，不表示那些资料也被公开许可。

打包命令：在已恢复全部模型的目录执行 `python tools/package.py --output <输出目录>`。它先核对模型，生成逐文件清单，然后输出 ZIP 和 SHA256SUMS；默认输出到项目旁的 `arknights-character-console-release`。
