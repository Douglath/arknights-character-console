# 使用、导出与常见问题

主程序使用 Python 标准库 HTTP 服务，默认端口 8781；冲突时自动使用可用本机端口，以启动输出为准。浏览器不能访问时检查终端是否仍开着，然后复制其中的地址。完整解压后再启动，不要在压缩软件内打开。

档案中拖动模型旋转，滚轮缩放。按 `/` 聚焦搜索，方向键切换角色。名录适合核对资料，全景按分组浏览模型缩略图。组合筛选可叠加，使用“重置筛选”恢复。

GLB 下载保持原字节，包含文件本身的网格、骨架和内置动画，不自动带入外部运行脚本。再分享请保留 CC BY-NC 4.0 署名和许可说明，建议另附 ASSET-USAGE.md、NOTICE 与 LICENSES/CC-BY-NC-4.0.txt。

单体 HTML 内嵌模型和渲染代码，没有 HTTP 或字体网络依赖。双击即可打开并切换动作/骨骼；许可文本也在页面内。此导出不是整个控制台的 HTML 镜像。

若模型空白：确认浏览器启用硬件加速和 WebGL 2，尝试更新显卡驱动或换 Chrome/Edge。运行 `python tools/verify.py` 检查模型是否完整。大型模型的首次加载可能稍慢。
